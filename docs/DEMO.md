# Demo path

The competition demo should use an invented or disposable MOCK room and show these transitions:

1. Launch Draft Day Cockpit and its dedicated Chrome profile.
2. Show **Installed**, then **Connected** and **Bound** as the owner selects the Yahoo mock lobby.
3. Enter a MOCK room and show its observed room size and draft slot.
4. Show the room refused before explicit MOCK authorization.
5. Authorize the observed room and connect it to the selected target configuration.
6. Show the recommendation move as the visible draft board changes.
7. Close Chrome, reopen it from the cockpit, and prove the same profile is recovered without an
   extra lobby tab.
8. Disconnect the bridge and show **Source unavailable** plus halted writes.

Before recording, confirm that no real account, league, team, room, session, receipt, local path, or
notification content is visible.
