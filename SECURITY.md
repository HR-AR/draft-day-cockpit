# Security policy

Do not open a public issue containing browser profiles, credentials, cookies, tokens, headers, page
bodies, account details, real league or room IDs, or local filesystem paths.

For a sensitive report, use GitHub's private vulnerability reporting for this repository. Include a
minimal reproduction with invented identifiers whenever possible.

Supported security fixes target the current `main` branch. The project fails closed when profile,
process, selected-tab, or room identity cannot be proven.
